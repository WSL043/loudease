# LoudEase Chrome 웹 스토어 등록 문안

Review status: Draft - fluent review required before publishing

## 제품 이름

LoudEase

## 요약

음소거 상태와 플레이어 음량을 유지하면서 웹 오디오의 큰 소리와 작은 소리를 로컬에서 균형 있게 조정합니다.

## 자세한 설명

LoudEase는 음량 차이가 큰 웹 오디오를 더욱 편안하게 들을 수 있도록 합니다.

탭에서 확장 프로그램을 열면 해당 탭의 오디오를 로컬에서 조정하도록 승인할 수 있습니다. LoudEase는 탭의 오디오를 실시간으로 분석해 갑자기 커지는 부분을 줄이고 작은 소리의 디테일을 신중하게 높입니다. 모든 순간을 같은 음량으로 만드는 대신 원래 소리의 강약 관계를 유지합니다.

주요 기능:

- 빠른 보호 처리로 갑자기 커지는 부분을 줄입니다.
- 헤드룸을 보호하면서 작은 소리의 디테일을 신중하게 높입니다.
- 페이지의 음소거 상태와 플레이어의 현재 음량을 유지합니다.
- 다른 탭으로 이동해도 승인된 탭의 오디오 조정을 계속합니다.
- 일반적인 동영상, 음악, 라이브 스트리밍 및 기타 탭 오디오에 사용할 수 있습니다.
- Web Audio와 AudioWorklet으로 PCM 오디오를 로컬에서 처리합니다.
- 광고, 분석 도구 또는 원격 실행 코드를 포함하지 않습니다.

Chrome에서는 새 탭을 캡처하기 전에 사용자 동작이 필요합니다. 오디오를 조정하려는 새 탭마다 LoudEase를 한 번 열어 주세요. 일반적인 페이지 이동 중에는 캡처가 중지되거나 탭이 닫힐 때까지 승인이 해당 탭에 유지됩니다.

오디오 효과는 원본 콘텐츠와 재생 장비에 따라 달라질 수 있습니다. LoudEase는 청취 편의 도구이며 청력 보호 장비나 의료기기가 아닙니다.
