# LoudEase Chrome 웹 스토어 등록 문안

Review status: Draft - fluent review required before publishing

## 제품 이름

LoudEase: 자동 볼륨 노멀라이저

## 요약

자동 볼륨 평준화: 갑작스러운 큰 소리와 광고는 줄이고 작은 대사는 키웁니다. 클릭 없이 자동, 기기 내 처리.

## 자세한 설명

LoudEase는 Chrome용 자동 볼륨 노멀라이저입니다. 갑자기 커지는 광고와 큰 소리는 낮추고 잘 안 들리는 작은 대사는 키워서 볼륨을 계속 조절하지 않아도 됩니다.

설치하고 재생하기만 하면 됩니다. 클릭도 설정도 필요 없습니다. 일반 웹페이지에서 재생 중인 동영상과 오디오를 자동으로 조절하며, 작동 중에는 도구 모음 아이콘에 ON이 표시됩니다.

- 광고, 깜짝 효과음, 갑작스러운 피크를 낮춥니다(빠른 보호와 5 ms 룩어헤드 리미터).
- 작은 대사와 소리가 작은 동영상을 키웁니다(상한 있음, 강도 조절 가능).
- 동영상, 방송, 채널 간 볼륨 차이를 줄입니다.
- 사이트 음소거와 플레이어 볼륨을 항상 존중합니다.
- 3단계 목표 수준, 사이트별 규칙, 사이트별 끄기 스위치.
- Web Audio와 AudioWorklet으로 기기에서만 처리합니다. 계정, 광고, 분석이 없습니다.
- 11개 언어 지원.

YouTube와 Bilibili에서 클릭 없이 동작하는 것을 확인했습니다. Chrome이 보호하는 오디오(CORS 없는 교차 출처, DRM, 자체 오디오 그래프를 쓰는 페이지)는 자동으로 연결할 수 없으므로 해당 탭에서 LoudEase를 한 번 열어 전체 탭 캡처를 사용하세요.

오디오는 기기에서만 처리되며 녹음되거나 전송되지 않습니다. 가벼운 로컬 관찰기는 페이지 미디어 상태(재생, 음소거, 볼륨)만 사용하고 페이지 텍스트, 양식, 쿠키, 자격 증명은 읽지 않습니다. LoudEase는 청취 편의를 위한 도구이며 청력 보호 장치나 의료 기기가 아닙니다. 현재 공개 베타입니다.
