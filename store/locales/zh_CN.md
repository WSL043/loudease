# LoudEase Chrome 应用商店文案

Review status: Draft - fluent review required before publishing

## 产品名称

LoudEase

## 简介

在本地平衡网页音频的响亮与轻柔片段，同时尊重静音状态和播放器音量。

## 详细说明

LoudEase 让音量起伏较大的网页音频听起来更舒适。

在某个标签页中打开扩展程序，即可授权对该标签页的音频进行本地平衡。随后，LoudEase 会实时分析该标签页的音频，减弱突然变响的片段，并适度提升较轻的细节。它会保留声音原有的层次，而不是把所有内容强行调整到同一音量。

主要功能：

- 通过快速保护机制减弱突然变响的片段；
- 在保留余量的前提下，适度提升较轻的细节；
- 尊重网页静音状态和播放器的当前音量；
- 切换到其他标签页后，仍可继续平衡已授权标签页的音频；
- 适用于常见的视频、音乐、直播和其他标签页音频；
- 使用 Web Audio 和 AudioWorklet 在本地处理 PCM 音频；
- 不含广告、分析工具或远程可执行代码。

Chrome 要求先由用户执行操作，扩展程序才能捕获新的标签页。请在每个需要平衡音频的新标签页中打开一次 LoudEase。在正常导航期间，授权会一直与该标签页关联，直到捕获停止或标签页关闭。

音频效果会因音源和播放设备而异。LoudEase 是提升聆听舒适度的工具，并非听力保护装置或医疗器械。
