# LoudEase Chrome 線上應用程式商店文案

Review status: Draft - fluent review required before publishing

## 產品名稱

LoudEase：自動音量平衡器

## 摘要

自動音量平衡：壓低突然的大聲與廣告，提亮聽不清的小聲對白。無需逐一點擊分頁，本機處理不上傳。

## 詳細說明

LoudEase 是 Chrome 的自動音量平衡器。它會壓低突然衝出來的廣告與大聲，提亮聽不清的小聲對白，讓你不用再頻繁調整音量。

裝好、播放就行，不需要點擊，也不需要設定。LoudEase 會自動平衡一般網頁中正在播放的影片與音訊，運作時工具列圖示會顯示 ON。

- 壓低廣告、驚嚇音效與突然的峰值（快速保護加 5 ms 前瞻限幅）；
- 提亮小聲對白與音量偏小的影片（有上限、強度可調）；
- 不同影片、直播、主播之間的音量更穩定；
- 始終尊重網頁靜音與播放器音量；
- 三檔校準目標、依網站規則與依網站一鍵關閉；
- 完全在本機以 Web Audio 與 AudioWorklet 處理，無帳號、無廣告、無分析工具；
- 支援 11 種介面語言。

已在 YouTube 與 Bilibili 實測無需點擊即可生效。少數音訊因 Chrome 的保護無法自動接入（缺少 CORS 的跨來源媒體、DRM 串流、自建音訊圖的頁面），此時在該分頁開啟一次 LoudEase 即可改用整頁接管。

音訊只在你的裝置上處理，不會被錄製或上傳。輕量本機觀察器只讀取頁面媒體狀態（是否播放、靜音、音量），不讀取頁面文字、表單、Cookie 或憑證。LoudEase 是提升聆聽舒適度的工具，並非聽力保護裝置或醫療器材。目前為公開測試版。
