# LoudEase Chrome 線上應用程式商店文案

Review status: Draft - fluent review required before publishing

## 產品名稱

LoudEase

## 摘要

在本機平衡網頁音訊的響亮與輕柔片段，同時遵循靜音狀態和播放器音量。

## 詳細說明

LoudEase 讓音量起伏較大的網頁音訊聽起來更舒適。

在分頁中開啟擴充功能，即可授權在本機平衡該分頁的音訊。接著，LoudEase 會即時分析該分頁的音訊，降低突然變大的聲音，並適度提升較輕柔的細節。它會保留聲音原有的層次，而不是強迫每個片段都維持相同音量。

主要功能：

- 透過快速保護機制降低突然變大的聲音；
- 在保留動態餘裕的前提下，適度提升較輕柔的細節；
- 遵循網頁靜音狀態和播放器目前的音量；
- 切換至其他分頁後，仍持續平衡已授權分頁的音訊；
- 適用於一般影片、音樂、直播和其他分頁音訊；
- 使用 Web Audio 和 AudioWorklet 在本機處理 PCM 音訊；
- 不含廣告、分析工具或遠端可執行程式碼。

Chrome 規定必須先有使用者操作，擴充功能才能擷取新的分頁。請在每個想要平衡音訊的新分頁中開啟一次 LoudEase。在一般導覽期間，授權會持續附加於該分頁，直到擷取停止或分頁關閉。

音訊效果會因來源素材和播放設備而異。LoudEase 是提升聆聽舒適度的工具，並非聽力防護用品或醫療器材。
