# LoudEase 实现技术文档

本文对应 `0.7.1` 当前代码。运行时代码与可执行测试是最终事实来源。

## 1. 产品边界

扩展处理的是用户明确授权的标签页音频，不是系统总线音频。Chrome 要求 `tabCapture` 必须由用户调用扩展后启动，因此无法静默接管所有从未授权的新标签页。

主链路：

```text
用户点击扩展
  -> background 获取一次性 tabCapture streamId
  -> offscreen 消费 MediaStream
  -> leveler-v3 AudioWorklet
  -> 播放器音量边界
  -> 本机输出
```

旧的页面级 `createMediaElementSource()` 引擎已退出运行时。`content/bridge.js` 只观察媒体数量、播放状态、静音和播放器音量，不处理 PCM。

## 2. 模块职责

- `background.js`：用户手势、streamId、offscreen 生命周期、多标签 session 编排、设置和状态聚合。
- `content/bridge.js`：轻量页面观察，提供播放器音量和媒体状态提示。
- `offscreen/index.js`：每个标签页的 `CaptureSession`、AudioContext、工作线程和清理。
- `offscreen/leveler-worklet.js`：正常路径中的计量、响度目标、增益包络、播放器边界和前视限幅。
- `offscreen/meter-worklet.js` / `limiter-worklet.js`：统一 worklet 加载失败时的保守降级组件。
- `popup/`：授权入口、真实状态、双强度控制和恢复操作。
- `monitor/`：高级设置、诊断导出和开发版本机诊断开关。
- `shared/core.js`：可单元测试的设置归一化和 DSP 策略函数。

## 3. DSP

工作线程以约 20 ms 为一帧，维护：

- 当前 20 ms 帧作为快速压低窗；
- 约 100 ms 的小声响度检测窗，取最近 5 帧能量中位数；
- 400 ms momentary 窗；
- 3 s short-term 窗；
- 约 200 ms 的提小声峰值窗。

输入经过近似 K-weighting。信号门采用开闭不同阈值，避免静音边缘反复开关。大声与小声使用同一个约 `-29 dB` 目标，最大提升 `34 dB`，最大压低 `30 dB`。提小声满档时可额外使用最多 `15 dB` 的受控 limiter 预算，使单个短促尖峰不再挡住整段小声；较低滑块值会同比缩小该预算。

压大声和提小声使用不同包络：压低快，提声约 `100 ms`，回落较稳。目标还有 `0.8 dB` 死区、`80 ms` 保持和每 20 ms 最多 `3 dB` 的上升步长，在增强拉齐速度的同时避免非连续跳变。

最终使用 5 ms 前视、声道联动的 sample-peak limiter，默认 ceiling 为 `-3 dBFS`。安静段、静音或正常播放后突发大声时，过渡保护会比较上一 20 ms 输入峰值；跨过 `-18 dBFS` 且至少跃升 `6 dB` 时，按“压低大声”强度把 ceiling 从 0 档的 `-9 dBFS` 逐步收紧到满档的 `-24 dBFS`，并至少保持 40 ms，给控制帧时间完成保护增益。当前尚未做 4x 过采样真峰值估计。

## 4. 播放器音量

播放器静音或音量为零时输出硬静音。播放器音量状态可靠时：

- 提小声预算随播放器音量降低；
- limiter ceiling 同比降低；
- 扩展不修改网页的 `media.volume`。

状态未知或冲突时，默认禁止向上增益，保留向下保护。这个边界只能约束软件输出，不能控制系统、声卡、功放或耳机声压。

## 5. 多标签与切源

每个已经授权的标签页在 offscreen 中拥有独立 session。切换浏览器焦点不会停止已有 session。站点更换 `<video>`、直播流或 SPA 路由时，tabCapture 仍跟随标签页混合输出，不需要重新绑定媒体元素。

## 6. 状态真实性

popup 只有在以下条件成立时才显示正在处理：

- capture session 处于 active/processing；
- worklet 已上报 signal tick；
- meter 状态仍在 TTL 内；
- 没有 mute、错误或停止状态覆盖。

开关打开只代表用户意图，不等于音频已经接管。

## 7. 构建与隐私

仓库提供两个 allowlist 构建：

- `dist/github-dev`：保留默认关闭的 localhost 开发诊断；
- `dist/store`：删除 localhost 权限、文案、符号和网络代码。

商店验证器会拒绝开发目录、日志、密钥、压缩包、动态执行、localhost 字符串和缺失引用。音频样本始终留在本机 Web Audio 图中。
