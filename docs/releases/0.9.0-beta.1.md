# LoudEase 0.9.0 Beta 1

LoudEase now balances audible video and audio on its own. Opening the extension on every tab is no longer required.

## What changed

- **Automatic mode.** A content script attaches audible, eligible `<audio>`/`<video>` elements to the existing programme-leveler AudioWorklet. The toolbar icon shows **ON** while it works. Per-site off switch in the popup.
- Cross-origin media without CORS, DRM media, and pages that build their own Web Audio graph are never attached (Chrome would silence them); the popup falls back to the existing one-click tab capture for those.
- A tab under user-invoked capture is bypassed by automatic mode, so audio is never processed twice. A stalled or failed worklet bypasses to a direct connection.
- New listing name, summary and description; new `web_accessible_resources` (the two AudioWorklet files) and a static content script on HTTP(S) pages. Existing host permissions are unchanged.
- The DSP is unchanged.

## Evidence boundary

- `node tools/e2e_auto_mode.js`: 10/10 (no-click attach, quiet lift under strict CSP, shadow DOM, CORS, declined cross-origin, muted media, per-site switch).
- Real sites with no click: YouTube video and Bilibili video. Twitch, Vimeo and Reddit were not verified.
- Tab-capture capture matrix 8/8; stripped store package verified.
- Not covered by automatic mode: `new Audio()` elements never inserted into the page, and Web Audio-only sites.
- This is a public beta, not a hearing-protection or universal compatibility claim.
