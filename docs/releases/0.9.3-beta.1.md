# LoudEase 0.9.3 Beta 1

Fixes a case where automatic mode looked connected but was not balancing the audible video.

## What changed

- Automatic mode now tracks the last real signal. A player that is attached but carries no sound (for example a hidden, preloaded video on Douyin) no longer keeps the popup on "Connected" and no longer blocks the whole-tab capture fallback.
- On pages with several players, the one that carries signal is the one the popup reports.
- When the tab is audible but the automatic graph carries no fresh signal, the popup offers (and, on opening, starts) whole-tab capture.

## Evidence boundary

- Unit tests, the static suite, automatic-mode e2e 14/14, tab-capture matrix 8/8, slider persistence and stripped-package verification passed. The Douyin case was reasoned from page structure and unit tests; it was not reproduced on a live logged-in Douyin session. This is a public beta, not a hearing-protection claim.
