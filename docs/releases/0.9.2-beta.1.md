# LoudEase 0.9.2 Beta 1

Small safety and clarity update on top of 0.9.1's automatic mode.

## What changed

- **Fix:** full-tab capture in 0.9.0 and 0.9.1 silently used the older fallback graph instead of the programme-leveler AudioWorklet. It now uses the leveler. Automatic mode was not affected.
- The popup explains when it falls back to full-tab capture because a site's audio cannot be attached automatically.
- Video-call sites are excluded from automatic mode.
- New automatic-mode tests for DRM media and pages that build their own Web Audio graph (both are declined, never silenced).

## Evidence boundary

- No change to the leveler algorithm itself since 0.9.1; the fix is in how the capture page loads it. The capture tests now require the leveler worklet to be active.
- Full static/DSP suite, automatic-mode e2e, tab-capture matrix 8/8, slider, 30 s long-run and stripped-package verification passed for this version. This is a public beta, not a hearing-protection claim.
