# LoudEase 0.8.2 Beta 1

This prerelease brings GitHub distribution up to the same `0.8.2` version currently published in the Chrome Web Store.

## What changed

- Added a configurable target-loudness baseline from `-22 dB` to `-16 dB` for gentler or stronger balancing.
- Added compact, voluntary Chrome Web Store review and GitHub Star actions.
- Kept the existing local-only audio path, permission set, mute/player-volume boundaries, bounded quiet lift, and fast loud protection unchanged.

- A current `0.8.2` native audible endpoint start/stop A/B and the broader two-hour mixed-content listening gate remain outstanding. This is a public beta, not a universal compatibility or hearing-protection claim.

## Install

Ordinary users should install from the [Chrome Web Store](https://chromewebstore.google.com/detail/gdkaclfjhmenjhoemdkjlpafdhengjog) for automatic updates. The attached ZIP is the same stripped runtime for trusted testers who deliberately use Chrome Developer mode.
