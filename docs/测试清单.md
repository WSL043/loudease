# 测试清单

## 加载检查

- `chrome://extensions/` 能成功加载目录。
- 扩展卡片没有 manifest 错误。
- 弹窗中文没有乱码。
- 弹窗显示版本号。

## 基础网页

- 打开 YouTube 或 B 站视频后，不需要手动启动即可生效。
- 播放器音量调低后，开启插件不应突然变大；输出应遵守播放器音量。
- 切换视频、刷新页面、SPA 跳转后仍会重新扫描。

## 听感检查

- 刷视频：忽大忽小应明显减少。
- 看视频：对白更稳定，但不应像广播电台一样被压扁。
- 人声：大声更稳，背景噪声不应被夸张放大。
- 音乐：动态保留更多，不应明显破音；不应有压缩器发糊感。
- 夜间：突然大声应明显被压住。

## 异常检查

- 关闭扩展开关后，原网页声音仍能正常播放。
- 页面没有 `createMediaElementSource` 未捕获错误。
- 反复切换模式、强度、刷新页面，不应出现声音重复、延迟明显增大或完全无声。
